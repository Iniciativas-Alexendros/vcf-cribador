zedazo

Tu agenda, pasada por el zedazo fino.

Criba, normaliza, clasifica y deduplica contactos VCF exportados desde ProtonMail, Google Contacts o Apple iCloud. Reglas deterministas, auditoría trazable y procesamiento local: no es un SaaS ni una nube de agendas.

Código en GitHub Crate en crates.io docs.rs

Qué hace

  • Pipeline VCF: parsear, normalizar, clasificar, cribar y deduplicar.
  • CLI oficial de automatización (cargo install zedazo).
  • GUI + API self-hosted en tu máquina (loopback o remoto con HTTPS y token). Esta URL es la ficha pública del producto, no la interfaz de cribado.
  • Licencia dual MIT OR Apache-2.0. MSRV Rust 1.80+.

Instalar y cribar

cargo install zedazo
zedazo cribar contactos.vcf -o limpio.vcf -a auditoria.tsv
